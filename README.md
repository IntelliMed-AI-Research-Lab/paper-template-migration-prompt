# 📄 Paper Template Migration Prompt

A reusable, general-purpose AI prompt for migrating a LaTeX academic paper from one journal or template format to another. Preserves all content, sections, figures, tables, and citations while adapting structural formatting, packages, and bibliography style.

---

## 🎯 Purpose

Academic papers often need to be reformatted when submitting to a different journal or conference — each with its own LaTeX class, package requirements, and structural conventions (author blocks, abstract environments, bibliography styles, etc.).

Manually porting a paper between templates is tedious and error-prone. This prompt lets you hand off that structural conversion to an AI assistant, while keeping full control over your actual scientific content.

---

## 🚀 How to Use

1. Copy the prompt template below.
2. Fill in the dashed blanks (`----------`) with your specific details.
3. Attach **two files** to your message:
   - Your current paper's full `.tex` file
   - The target template's `.tex` file (e.g. a blank/dummy shell from the journal you're submitting to)
4. Paste the filled-in prompt as your message text, along with the attachments.

The assistant will return a fully converted `.tex` file, ready to paste directly into the new template's `main.tex`.
